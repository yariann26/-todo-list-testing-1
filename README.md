# Todo-List Testing

Репозиторий с тестовой документацией для приложения «Список задач».

## Структура
- `requirements.md` — требования к приложению
- `test-cases/` — тест-кейсы
- `test-suites/` — тестовые пакеты
- `test-run/` — результаты прогона
- `bug-reports/` — баг-репорты
- `coverage/` — отчёт о покрытии
